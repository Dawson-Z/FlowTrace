## 功能

| 领域 | 说明 |
| --- | --- |
| **进程列表** | 按名称或 PID 过滤（始终忽略大小写）、6 种排序模式、同名进程合并、每行实时"今日"列 |
| **历史** | SQLite 支撑的帧历史（WAL + `synchronous=NORMAL`），挂在弹窗迷你图之后；独立窗口提供应用用量表、小时 × 日期热力图与示警日志，均可导出 CSV |
| **接口维度** | 第二个独立 `nettop`（socket 模式），将外部流量按 Wi-Fi / 有线 / 本地直连 / 其他分桶；弹窗底部堆叠条 |
| **菜单栏总量** | 可选在 ↙/↗ 速率旁显示今日 `D` 与配额周期 `P` 分段 |
| **配额示警** | 80% / 100% / 自定义阈值的本地通知，按月 / 周 / 日分组，每周期每阈值去重 |
| **进程流量示警** | 7 日日用量中位数 × 倍数 **且** 绝对 MB 下限；按本地日 + 进程 + 方向去重（表唯一索引） |
| **保留期** | 可配置保留窗口 + 每日检查点：自动清理，或提醒通知 + 手动清理；修改任一存储设置立即重查保留期 |
| **设置窗口** | 存储与清理、配额、示警、外观、强调色、21 种语言 —— 全部运行时生效 |
| **强调色** | 跟随系统或自定义；自定义色在 AppKit 无法着色的手绘控件上同样生效 |
| **本地化** | 21 种语言、运行时切换、跟随地区感知的日期格式 |

## 通知权限 —— 预期行为

配额示警、进程流量示警与保留期提醒都是本地通知，因此需要系统权限：

- 当某个会发通知的功能已开启但权限缺失时，对应的设置面板（配额 / 示警 /
  存储）会显示内联橙色警告与快捷操作 —— 权限曾被拒绝时显示**打开系统设置**，
  从未询问过时显示**允许通知**。
- 启动时，若任一通知类功能已开启但权限被拒绝，应用弹出一个说明框，解释哪些
  通知无法送达，同样提供上述两个操作，外加永久的**不再提醒**选项（无论是否
  选择，设置面板内的警告都保持显示）。
- 通知权限与代码签名身份绑定。本分支使用稳定的自签名身份，因此同一身份签名
  的更新会保留授权；由他人重新构建则是另一个身份。
- 内部实现上，投递前先检查授权状态（未授权时系统 `add` 也报告无错误），被
  拒绝的投递按 15 分钟退避重试，而不是被记为已发送。

## 已知限制

- 用户空间的 `nettop` 无法按域名或连接归属流量。
- 自签名且未公证：每次下载后的首次启动都会被 Gatekeeper 阻止，直到手动放行
  （见 README）。
- **备份数据库时必须连同侧车文件一起备份** —— WAL 模式下磁盘上是
  `history.sqlite3` 加 `history.sqlite3-wal` 与 `history.sqlite3-shm` 三个
  文件；只拷贝主文件会丢失最近的数据。
- 测试套件**不是**隔离的：它运行在应用内部，会触碰真实的数据库、日志文件以
  及（此前）真实的 `UserDefaults` 域。在你在意的机器上跑 `xcodebuild test`
  之前，先看 AGENTS.md → Build。

