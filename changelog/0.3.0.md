# 0.3.0 (research milestone 1)

Initial research milestone. This fork is private and not shipped.

## Added

- **Process search bar.** `iTrafficPlus/Feature/Search/ProcessSearchBar.swift` adds a TextField at the top of the popover. Filtering is owned by `SearchFilter` (pure function) and applied in `ListViewModel.updateData` so the existing PID-merge / sort / GC logic keeps its shape.
- **In-memory history ring buffer.** `iTrafficPlus/Feature/History/RingBuffer.swift` + `HistoryStore.swift` keep the last 60 frames of total in/out (about 2 minutes at the upstream's 2-second sample). `HistoryView.swift` renders a sparkline at the bottom of the popover.

## Touched (upstream files)

- `ITrafficMonitorForMac/Network.swift` — `Network` now also pushes each frame into `SharedStore.historyStore`.
- `ITrafficMonitorForMac/Model/ListViewModel.swift` — `updateData` now applies the search filter after the existing merge.
- `ITrafficMonitorForMac/ContentView.swift` — hosts `ProcessSearchBar` (top) and `HistoryView` (bottom).
- `ITrafficMonitorForMac/Store.swift` — owns the new `historyStore` singleton.

## Stripped from upstream

- `ITrafficMonitorForMac/Service/UpdateChecker.swift` — not included; this fork has no release channel to check.
- `ITrafficMonitorForMac/UpdateStatusView.swift` — not included; the popover no longer renders a clickable version line.
- `ITrafficMonitorForMac/MenuItem.swift` — kept (still used by the upstream's row links), but the `tooltipIfAvailable` helper is no longer needed because the only caller was the stripped UpdateStatusView.

## What did NOT change

- `NettopRunner.swift` — kept verbatim, including the `script -q /dev/null` TTY wrap and the retained stdin pipe.
- `Utils.swift` — kept verbatim; `getAppInfo` cache continues to back the per-row icon resolution.
- The 2-second sample / delta mode / first-frame-dropped rule.
- The "no network call at all" rule, hardened to "no network call period" in this fork.
