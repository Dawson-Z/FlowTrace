# 1.0.0 — FlowTrace

> **Prebuilt builds** are attached to the Releases page as a `.dmg` and a
> `.zip`. They are signed with a self-signed certificate (bundle id
> `local.FlowTrace`, signing identity **`Dawson`**) and are **not** notarised,
> so macOS blocks the first launch until you allow it — see the README's
> [First launch](../README.md#first-launch) section. Everything works in user
> space: no System Extension, no NetworkExtension, no extra entitlements.

1.0.0 is the **first numbered release** and the baseline going forward. It
contains the full feature set built during the 0.3.0 research-milestone period
(see [changelog/0.3.0.md](0.3.0.md) / [changelog/0.3.0.zh-CN.md](0.3.0.zh-CN.md)
for the milestone-by-milestone history) plus the notification-delivery work
finished immediately before this release.

## Features

| Area | What it does |
| --- | --- |
| **Process list** | Filter by name or PID (always case-insensitive), 6 sort modes, same-name merge, live per-row "today" column |
| **History** | SQLite-backed frame history (WAL + `synchronous=NORMAL`) behind the popover sparkline; a standalone window with an app-usage table, an hour × day heatmap and an alert log, each exportable to CSV |
| **Interface dimension** | A second, independent `nettop` (socket mode) bucketing external traffic into Wi-Fi / Wired / Local Direct / Other; stacked bar at the bottom of the popover |
| **Menu-bar totals** | Optional today `D` and quota-period `P` segments next to the ↙/↗ rates |
| **Quota alerts** | Local notifications at 80% / 100% / a custom threshold, grouped by month / week / day, deduplicated per threshold per period |
| **Process traffic alerts** | 7-day daily median × multiplier **and** an absolute MB floor; dedup by local day + process + direction (table unique index) |
| **Retention** | Configurable retention window with a daily checkpoint: automatic cleanup, or a reminder notification + manual clearing; editing any storage setting re-checks retention immediately |
| **Settings window** | Retention & cleanup, quota, alerts, appearance, accent colour, 21 languages — all applied at runtime |
| **Accent colour** | Follow system or custom; custom reaches hand-built controls where AppKit cannot be tinted |
| **Localization** | 21 languages, runtime switching, locale-aware date formatting |

## Notification permission — what to expect

Quota alerts, process traffic alerts and the retention reminder are all local
notifications, so they need the system permission:

- When a notifying feature is enabled but the permission is missing, the
  relevant Settings panes (Quota / Alerts / Storage) show an inline orange
  warning with a shortcut — **Open System Settings** when the permission was
  denied, **Allow Notifications** when it was never asked.
- At launch, if the permission is denied while any notifying feature is on, the
  app shows one alert explaining what cannot be delivered, with the same two
  actions plus a permanent **Don't remind me again** opt-out (the Settings
  warnings stay either way).
- The permission is keyed to the code-signing identity. This fork is
  self-signed with a stable identity, so the grant survives updates signed with
  the same identity; a rebuild by someone else would be a different identity.
- Internally, delivery checks the authorization status before handing a
  notification to the system (`add` reports no error when unauthorized), and a
  refused delivery is retried with a 15-minute back-off instead of being
  recorded as sent.

## Known limitations

- User-space `nettop` cannot attribute traffic by domain or connection.
- Self-signed + not notarised: the first launch after every download is blocked
  by Gatekeeper until allowed (see the README).
- **Back up the database together with its sidecars** — in WAL mode the on-disk
  database is `history.sqlite3` plus `history.sqlite3-wal` and
  `history.sqlite3-shm`; copying only the main file loses the most recent data.
- The test suite is **not** isolated: it runs inside the app and touches the
  real database, log file and (previously) real `UserDefaults` domain. See
  AGENTS.md → Build before running `xcodebuild test` on a machine you care
  about.
